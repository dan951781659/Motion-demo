# Motion 两端 UI 继承说明

以当前设备源码及 Flutter APP 规范为基础；设备端常规页面浅色 #F5F5F5、主色 #0A84FF、卡片圆角 8；APP 页面 #F5F5F5、默认主色 #2563EB、卡片圆角 12，保留 58 高浮动胶囊和四 Tab。深色分别为设备蓝黑和 APP 黑底分层。训练页以用户指定训练 Demo 的深色 HUD、固定画中画及抽屉结构为参考。

本次不改头像、产品 icon、语言扩展、体测模块及最低重量。单边最低 3kg、双边最低 6kg。注销仅 APP；常见问题不做反馈表单；床体控制仅设备，APP 同步状态。

字号、间距继承现有项目语义；文案原需求的 1sp 缩放步长改为项目要求的 2sp；设备像素设计值不重复乘物理密度。

当前关键页面为按源码模块重建的目标 Demo，原 HTML 及旧 APP 包作为历史参考保留；不是当前 develop 全页面像素复刻。最终范围以父目录《Motion最终整合需求文档》为准。
